# Rev A docs (archived)

Rev A was the rod-lens version: a 1.6 mm board with BAW56 diodes and a Samtec 2 x 2 long-post header, a clear acrylic
rod in a printed carrier, and a printed clip and cover. It was replaced by rev B on 2026-09-25 and was never built.

These files are kept as they were on 2026-09-25, for history only:
- `README-revA.md` - the project README for rev A;
- `ORDERING.md`, `ASSEMBLY.md`, `SAFETY-AND-TEST.md`, `DESIGN.md`, `FIRMWARE-NOTES.md` - the rev A docs.

Their relative links point at the old layout, so many of them no longer resolve. Rev A's PCB and housing files are in
`../pcb/` and `../housing/`. For the current design, see the project [README](../../../README.md).
